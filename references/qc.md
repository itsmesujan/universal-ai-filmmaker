# Quality Control and Repair

Inspect each accepted clip against the canonical project state.

## Checks

Identity
Style
Anatomy
Motion
Physics
Camera
Composition
Lighting
Background
Objects
Text
Audio
Temporal stability
Continuity
Emotional performance

## Status

PASS — meets project requirements.
REPAIR — a targeted correction is likely to work.
REGENERATE — fundamental generation failure.
REPLACE — use another model/method/shot design.

## Failure diagnosis

FACE_CHANGED → strengthen reference identity.
COSTUME_CHANGED → restore canonical costume reference.
STATIC_VIDEO → define explicit subject/environment motion.
SLIDESHOW → add temporal action.
CAMERA_CHAOS → reduce camera movement.
PHYSICS_FAILURE → simplify action.
WRONG_COMPOSITION → regenerate the keyframe.
CONTINUITY_FAILURE → compare against the ledger.
