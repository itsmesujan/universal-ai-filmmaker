# Rubric — Shot Design (SHOTS gate)

Score each dimension 0–5. Record evidence (shot ids, quotes) beside every score.

| Dimension | 0 | 3 | 5 |
|---|---|---|---|
| Story purpose | no purpose stated | purpose stated per shot | each shot either advances or reveals, and is traceable to a beat |
| Action clarity | multiple vague actions | one action per shot | one observable action with a defined end state |
| Camera discipline | random or unmotivated | one movement, stated | movement motivated by the beat, lens consistent per scene |
| Coverage economy | redundant shots | coverage maps to beats | the smallest sufficient coverage; no shot could be cut without loss |
| Continuity specification | no anchors | canon ids present | canon ids plus state, damage, prop position, direction |
| Axis and eyeline | unplanned | direction stated per shot | axis locked across the scene, reversals via neutral shots |
| Risk honesty | risk absent | risk_level present | risk matches the axes, with budget and a fallback plan |
| Model realism | capabilities assumed | durations plausible | durations and methods fit verified limits, degraded mode noted |

**Ship** at ≥ 32/40 with no dimension below 3. Anything at 2 or below is repaired before
generation starts — shot design is the cheapest place to fix anything.

## Reviewer questions

1. If I delete this shot, what information or feeling do I lose?
2. Which beat does it serve, and which shot before/after does it connect to?
3. Could the action be split so that a failure stays local?
4. What exactly can drift here, and is it written down?
